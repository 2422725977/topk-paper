\section{Implementation details of Algorithm 1 and experimental parameters}
\label{app:impl}
Algorithm 1 (GraphWalk-SE, Section 5 of the main text) uses calibrated devices that are not part of Theorem 5.1: active-set query concentration, and contrast radii
$\tau_{ij}=\sqrt{2\log(4n^2r/\delta)\,s_{ij}^2}+2\log(4n^2r/\delta)\,s_{ij}^2$ with $s_{ij}^2=P_{ii}+P_{jj}-2P_{ij}$, $P=H^{+}$ the pseudo-inverse of the observed Fisher information, per-edge curvature $\sigma'(\hat d_e)$ clipped to $|\hat d_e|\le 3$, a round budget that doubles, and $10\%$ full-graph mixing in opponent sampling.  A capped run (E4) finishes its current doubling round, so realized $T$ can exceed the cap by up to one round.  All error rates are measured on fresh random seeds.

\paragraph{Experimental parameters and reproducibility.}
Table~\ref{tab:params} lists the parameters of every experiment.  Instances are drawn once per configuration (not per repetition), as $\theta_i=3\tanh\big((k-\tfrac12-i)\,\Delta/3\big)$; repetitions differ only through algorithmic randomness, seeded deterministically from (experiment, configuration, repetition index), so every run is reproducible from the code in the accompanying repository (which also archives all \texttt{results/*.json} files, Python and NumPy versions).  Subsections of the main text are ordered by narrative rather than by experiment number.
