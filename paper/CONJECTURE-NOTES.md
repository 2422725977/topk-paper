## 0. 要证什么

**Conjecture 4.2（论文原陈述）**：存在 c > 0，使得在任何有界度、代数连通度 λ_G 的连通图上，
任何（无均衡限制的）δ-正确算法在某个满足 Condition 3.1 的实例上需要
T ≥ c·(n/(λ_G Δ²))·log(1/δ) 次比较。

**预期路线（SPEC/正文记的打包论证）**：构造一族难分辨实例 → 证明两两 KL 受限 → Fano/Assouad。

## 1. 打包论证骨架（moving-window family）

设 1 ≤ k ≤ n/2，取窗口族 W_j = {j, j+1, …, j+k−1}，j = 1, …, n−k+1（共 n' = n−k+1 个假设）。
实例 θ^{(j)} 定义（与图 G 无关，只用到编号集 [n]）：

- i ∈ W_j：θ^{(j)}_i = +Δ/2 − r(i,j)·η，其中 r(i,j) 是 i 在窗口内的名次（0-based）；
- i ∉ W_j：θ^{(j)}_i = −Δ/2 − s(i,j)·η，s(i,j) 是 i 在窗口外的名次；
- η = Δ²/(8kB)（后面会用到 B 为动态范围上界）。

则：
(i) 每个实例的 top-k 集合恰为 W_j，且边界 gap = Δ（第 k 名 +Δ/2 − (k−1)η，第 k+1 名 −Δ/2）；
(ii) ‖θ^{(j)}‖∞ ≤ Δ/2 + nη ≤ Δ/2 + Δ²/(8B) ≤ B（只要 B ≥ Δ，Condition 3.1 满足）；
(iii) 输出正确 top-k 集合 ⟺ 恢复 J（窗口位置）。

**逐对差异**：θ^{(j)} − θ^{(j')} 仅在 W_j Δ W_{j'} 上非零。对 i ∈ W_j \ W_{j'}：
变化量 = |(+Δ/2 − rη) − (−Δ/2 − s'η)| ≤ Δ + kη ≤ Δ + Δ²/(8B) ≤ (3/2)Δ（取 Δ ≤ B）。
对同时属于两窗口的 i：变化量 = |r − r'|·η ≤ kη = Δ²/(8B)。

**KL 分解**：自适应算法下，KL(P^{(j)}‖P^{(j')}) ≤ Σ_t E^{(j)}[kl_t]（链式法则，标准），
其中第 t 次比较在边 e 上，由 KL 引理（论文 Lemma 3.2）：
- 若 e 至少一个端点在 W_j Δ W_{j'} 中：|h_e| ≤ 2·(3/2)Δ = 3Δ → kl_t ≤ C_B·9Δ²；
- 否则 |h_e| ≤ 2·Δ²/(8B) → kl_t ≤ C_B·Δ⁴/(16B²)。

记 N_inc(j,j') = 落在"对称差端点的关联边"上的比较次数。则
KL(j,j') ≤ 9C_BΔ²·N_inc(j,j') + C_BΔ⁴T/(16B²)。

## 2. 逐步核查

**步骤 1（构造合法性）✅ 成立**。(i)(ii)(iii) 直接验证；条件 B ≥ Δ（由 Δ ≤ B 给出）下 η 的选取自洽。
注意与 Wave 0 的教训一致：这里逐对差异被刻意压在 O(Δ)，避免了大跳变导致"每次比较 KL 是 O(1) 而非 O(Δ²)"的构造错误。

**步骤 2（逐对 KL 上界）✅ 成立**。链式法则对自适应算法成立（逐比较 KL 在 P^{(j)} 测度下取期望，
算法行为不依赖于 j′——它看不见假设标签）。KL 引理只要求两实例都满足 Condition 3.1 ✅（(ii) 已验证）。

**步骤 3（关联边计数）✅ 成立（这是关键一步，算了两遍）**。对固定边 e = (i, i+1)（一般图上是 e 的两个端点）：
"e 是 (j,j′) 的关联边" ⟺ i ∈ W_j Δ W_{j'} 或 i+1 ∈ W_j Δ W_{j'}。
固定 i：i ∈ W_j ⟺ j ∈ [i−k+1, i]（k 个取值）；故
#{有序对 (j,j′): i ∈ W_j Δ W_{j′}} = 2k(n′−k) ≤ 2kn′。
（对称：i 与 i+1 两个端点 → 至多 4kn′。）于是

(1/n′²) Σ_{j≠j′} N_inc(j,j′) = Σ_e m_e · #{e 关联的对}/n′² ≤ 4kT/n′。

**步骤 4（Fano）✅ 成立**。J 服从 [n′] 均匀先验；算法输出 top-k 集合，错误率 ≤ δ
⟹ I(J; output) ≥ (1−δ)log n′ − 1（Fano 之对偶形式，Cover–Thomas Ch. 8 标准结果）。
互信息的上界：I ≤ (1/n′²) Σ_{j,j′} KL(j,j′) ≤ 4kC_BΔ²T/n′ + C_BΔ⁴T/(16B²)。
合并：

T ≥ [(1−δ)log n′ − 1] / (4kC_BΔ²/n′ + C_BΔ⁴/(16B²))
  ≥ c·(n′·log n′)/(kΔ²)   （当 Δ ≤ Δ₀(n,k,B,δ)；常数显式可写）。

**结论：打包论证本身是通的——但证出的是 graph-independent 的下界 Ω((n/(kΔ²))·log(n/δ))，
里面没有 1/λ_G。**

## 3. 卡住的地方（本质性的，不是技术性的）

**1/λ_G 无法从这类论证中出来，而且有反证级的证据表明猜想按原陈述是假的。**

- 打包论证对**任何**连通图一视同仁：实例构造只用编号集，与 G 的几何无关；逐对 KL 的信号边
  （对称差的关联边）由算法自己的查询分布 m_e 决定，均衡性都不需要。因此这条路**不可能**
  产出一个随 λ_G 变差的下界。
- 更强地：猜想要求在路径图（λ_G ≈ π²/n²）上 T ≥ c·n³/(π²Δ²)·log(1/δ)。但移动窗口论证
  （若按上面第 2 节核查通过）给出上界意义上相容的 O((n/(kΔ²))·polylog) 可达率预期，且
  我们自己的 E2 数据（cycle, n=50, Δ=0.5, k=3：实测 T ≈ 5.7×10⁴）比猜想要求
  （n·n²/(Δ²λ_G)·c ≈ 3.2×10⁷·c，c ≥ 1）小三个数量级——除非 c ≤ 10⁻³，猜想按原陈述不成立。
  Wave 1 的实用算法是自适应集中采样的，这恰是 Remark 4.3 预言的"自适应击穿 Fiedler 论证"现象。

**所以卡住的真正一步是**：想给自适应算法证明任何**图相关**的下界，实例的"难信息"必须真的
需要穿过 G 的瓶颈传播；而 top-k 决策只依赖边界处的 O(1) 条信息，算法可以把查询集中到边界邻域，
绕开图的其他部分。E2c（哑铃桥跨边界，one-shot 估计器付出 3.92×）显示 one-shot 类算法有
连通度代价，但这不是下界——自适应算法原则上可以在桥上只花 1/Δ² 次。

## 4. 本次尝试的产出

1. **可证明的新命题（图无关自适应下界）**：对任何连通图 G、任何 δ-正确算法，
   T ≥ c·(n/(kΔ²))·log(n/δ)（Δ ≤ Δ₀；证明即第 1–2 节，常数显式）。
   它匹配全访问已知率（差 k 因子内的对数），且**不含 λ_G**。
   ——按任务规则未写进论文正文（正文保持 Conjecture 4.2 原状）；此证明未经第二双眼睛校对，
   投稿前需逐行复核（特别是 Fano 对偶形式的常数与 η 选取的自洽性）。
2. **猜想的修正建议（供未来修订）**：把 Conjecture 4.2 替换为：
   (a) 已证：图无关的自适应下界 Ω((n/(kΔ²))·log(n/δ))（第 4 节命题）；
   (b) 新猜想：自适应算法的图相关代价是否存在？——即是否存在图族与实例族使得
       任何自适应 δ-正确算法需要 ω(1) 倍于全访问率的比较次数？
       E2c 的 3.92× 只是 one-shot 估计器的常数，不构成自适应下界。
3. **对论文现状的影响**：论文正文 Remark 4.3 已说"均衡条件不能简单去掉"，与本笔记一致；
   论文第 6 节的实验解释（识别代价由边界几何主导）与本笔记的结论一致，无需改动。

## 5. 需要的额外工具（若要复活 1/λ_G 形式）

- 一个"信息必须穿瓶颈"的实例族：top-k 集合的判定强制依赖跨瓶颈对比，且算法无法用
  局部查询绕过——目前想不出如何阻止算法把查询集中到瓶颈邻域（这正是自适应的力量）。
- 或者换目标：证明**非自适应/低自适应**（如 r-round 自适应，r = o(log n)）算法的 λ_G 下界
  ——round-restricted 模型下 Fiedler 论证可能复活（每轮内查询分布是固定的，KL 摊薄论证成立）。
  这是一个干净的中间地带，建议作为下一步。
